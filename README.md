# Yuhan's Desk — five tools on one page

| Page | What it is |
| --- | --- |
| `index.html` | Home: greeting, four live numbers, five cards |
| `music.html` | QQ Music embed, plus a player for files on this computer |
| `study.html` | 4 subjects × 8 flash cards, with progress kept in the browser |
| `clock.html` | Analogue face, four world clocks, a 25/5 focus timer |
| `ledger.html` | The shared expense book, same storage key as the standalone ledger |
| `tarot.html` | Three-card draw from the twenty-two major arcana |

Hand-written HTML, CSS and JavaScript. No framework, no build step. Everything runs from
GitHub Pages and keeps its state in `localStorage`, except the music files, which never
leave the page.

Written by Yuhan Cai.
